# Repository workflow

The project lives at https://github.com/NinuGaming999/ECHOPOST on the `main` branch.

## Clone and run locally

```sh
git clone https://github.com/NinuGaming999/ECHOPOST.git
cd ECHOPOST
```

Open `project.godot` in Godot 4.x and press F5 to run.

## Continue development

- Work on a separate branch for larger changes.
- Keep commits focused, with a clear message describing the change.
- Run the smoke tests in Godot before merging.
- Do not commit API tokens, passwords, signing keys, or generated keystores.
- Keep the existing `NinuGaning_game` and `Ninugaming-apk` repositories separate from this game.

For contributions, see `../CONTRIBUTING.md`. The release roadmap is tracked in `ROADMAP.md`.
